  kubectl get pods -n {{ .Release.Namespace }} -l component=backend

To view frontend pods:

  kubectl get pods -n {{ .Release.Namespace }} -l component=frontend

========================================
ACCESSING THE APPLICATION
========================================

Frontend URL:
{{- if eq .Values.frontend.service.type "NodePort" }}

  The frontend is exposed via NodePort.

  Get the Node IP:
    kubectl get nodes -o wide

  Access the application at:
    http://<NODE_IP>:{{ .Values.frontend.service.nodePort }}

  Or use kubectl port-forward for local access:
    kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "todo-chatbot.frontend.serviceName" . }} 8080:{{ .Values.frontend.service.port }}
    Then access: http://localhost:8080

{{- else if eq .Values.frontend.service.type "LoadBalancer" }}

  Get the external IP address:
    kubectl get svc -n {{ .Release.Namespace }} {{ include "todo-chatbot.frontend.serviceName" . }}

  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
  Watch the status with:
    kubectl get svc -n {{ .Release.Namespace }} -w {{ include "todo-chatbot.frontend.serviceName" . }}

{{- else }}

  The frontend service is ClusterIP. To access it:
    kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "todo-chatbot.frontend.serviceName" . }} 8080:{{ .Values.frontend.service.port }}
    Then access: http://localhost:8080

{{- end }}

Backend API:

  The backend is only accessible within the cluster at:
    http://{{ include "todo-chatbot.backend.serviceName" . }}:{{ .Values.backend.service.port }}

  To access the backend API locally for testing:
    kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "todo-chatbot.backend.serviceName" . }} 8000:{{ .Values.backend.service.port }}
    Then access: http://localhost:8000

========================================
HEALTH CHECKS
========================================

Backend health endpoint:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "todo-chatbot.backend.serviceName" . }} 8000:{{ .Values.backend.service.port }}
  curl http://localhost:8000/health

Frontend health endpoint:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "todo-chatbot.frontend.serviceName" . }} 3000:{{ .Values.frontend.service.port }}
  curl http://localhost:3000/api/health
