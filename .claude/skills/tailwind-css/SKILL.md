# Tailwind CSS Expert

## Purpose
This skill provides expert-level knowledge of Tailwind CSS best practices, responsive design patterns, and optimization techniques.

## Expertise Areas

### 1. Tailwind Best Practices
- Use utility-first approach rather than creating custom CSS
- Leverage design tokens and consistent spacing scales
- Use semantic class ordering (positioning, layout, typography, visual)
- Prefer `@apply` for complex component variants when necessary
- Utilize arbitrary values sparingly and only when needed

### 2. Responsive Design Rules
- Mobile-first approach: Start with base styles, then add breakpoints
- Use Tailwind's responsive prefixes: `sm:`, `md:`, `lg:`, `xl:`, `2xl:`
- Implement responsive typography with `text-sm`, `text-base`, `text-lg`, etc.
- Use responsive spacing and sizing utilities
- Leverage responsive container queries where appropriate

### 3. Performance Optimization
- Use `@tailwind variants` to generate only needed responsive classes
- Enable `purge` in production to remove unused styles
- Leverage `dark:` variant for dark mode support
- Use `group-hover`, `focus-within` variants for interactive states

### 4. Common Patterns
- Flexbox and Grid layouts
- Card components with consistent padding and spacing
- Form styling with proper focus states
- Navigation patterns
- Modal and dropdown implementations

### 5. Accessibility
- Ensure proper contrast ratios using Tailwind's color palette
- Include focus-visible utilities
- Use semantic HTML with Tailwind classes
- Implement ARIA attributes where needed

## When to Use
Use this skill when:
- Creating responsive layouts
- Implementing component designs
- Optimizing Tailwind usage
- Ensuring accessibility compliance
- Applying consistent styling patterns
- Converting traditional CSS to Tailwind utilities
